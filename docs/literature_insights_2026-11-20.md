# What one depth view tells us about a potato

Research synthesis, 20 November 2026. The most informative experiment is to change one local observation on the same tuber and measure how far that change propagates into its inferred underside. A sensor artifact, a genuine one-sided protrusion and a genuine bilateral shape change can look similar from above. They imply different correct predictions. A second, practical question is whether whole-shape completion adds value over measuring the visible dimensions when the ultimate target is physical volume.

## Why local errors can have global effects

The current mirror baseline estimates height (H), sets the reflection plane at half that height, and assigns each retained upper vertex a lower partner at `H − z`. Before floor clipping, increasing the fitted height by 1 mm moves every otherwise unchanged lower partner by 1 mm. Changing a local height with the fitted height held fixed affects its own reflection. Changing the estimated height can also move the cutoff for upper-vertex inclusion. This gives us two distinct mechanisms to test with the same input. [Mirror implementation](../src/potato3d/completion/symmetry.py)

On 12 reserved synthetic families, the multiscale rule flagged 599 of 600 coherent-patch points. The survivor shifted the trusted maximum by 11.91 mm in one family. Across families the rule reduced patch hidden Chamfer from 8.1623 to 1.9534 mm versus the single-scale rule, while moving 46 of 108 evaluated narrow genuine-feature points. The 95th-percentile baseline achieved 1.7640 mm patch hidden Chamfer, and the multiscale method missed its prespecified noninferiority criterion. A candidate must improve on both the strong simple baseline and the feature-preservation failure. [Frozen multiscale study](multiscale_confidence_report.md)

**Proposed endpoint.** For a clean shape and its corrupted observation, keep the physical underside fixed. Measure (a) error against that underside and (b) how much the predicted underside changed between the two inputs. Render the two predictions in the same fixed frame from beneath on synthetic fixtures, and report coverage changes wherever only one prediction intersects a ray. A generic model that ignores the input can achieve zero change while producing a consistently wrong underside. Absolute reference error and preservation of genuine features expose that failure. A paired case where the underside really does change tests whether a method is excessively rigid.

| [DeepSDF, pp. 4–8](../output/pdf/papers/2019-DeepSDF.pdf) | The auto-decoder optimizes a latent shape code. | [GenPC, pp. 3–8, Table 3](../output/pdf/papers/2025-GenPC.pdf) | Depth prompting supplies a generative prior. | [RealPC, pp. 4–6, 14–15](../output/pdf/papers/2025-RealPC.pdf) | Railway scans exhibit nonuniform sampling, noise and topology unlike standard synthetic CAD data. | [DAPointRWKV, pp. 5–8](../output/pdf/papers/2026-DAPointRWKV.pdf) | An observation-to-prediction loss anchors visible geometry. | [Uncertain regions, pp. 3–7](../output/pdf/papers/2023-Uncertain-Regions.pdf) | For partly symmetric objects such as mugs, indistinguishable views can correspond to different hidden handle locations. A deterministic predictor must return the same completion for identical inputs. Use twins to assess ambiguity or coverage, and avoid claiming that a particular unobservable underside can be uniquely inferred. |

Zhang et al. already introduced separate visible- and missing-region Chamfer scores and used camera rays to constrain completion. A defensible contribution would be the controlled *response* of a remote, independently referenced surface to a local intervention, plus its relationship to physical volume. Establishing how well that transfers to real tubers remains an empirical question. ## Experiment with the highest information value

1. **Reserve new shapes by family.** Generate matched cases with a clean smooth body, a true unilateral lobe, a true bilateral lobe, and a sensor patch on a smooth body. Match observed width, amplitude and sampling density. Vary placement at the apex, flank and silhouette. Include both positive and negative depth offsets and structured boundary loss, and reserve exact-input twins for the ambiguity check.
2. **Hold the body fit constant across detail treatments.** Use the same robust superquadric and the same estimate of local surface detail. Compare body alone, detail restored on the visible side, and the same detail reflected to the hidden side. Keep the existing mirror, fixed q95 and feature-preserving smoothing as comparisons. Separately repeat the mirror with its height fixed to the paired clean fit, as a diagnostic available only in the controlled experiment. That isolates height sensitivity from copying local geometry.
3. **Keep outcomes interpretable.** For coherent artifacts measure hidden-surface error and prediction change away from the affected region. For genuine lobes measure signed amplitude recovery and local reference error. For bilateral lobes require hidden-lobe recovery. Report volume separately and add an estimator based only on visible dimensions. Determine a useful effect size and tolerable genuine-feature loss on development data, freeze both before confirmation, and estimate paired intervals by family or physical tuber.
4. **Test what the observation contributes.** Compare a training-only average shape, a size-fitted prior and an individually fitted model under the same pose information. Where morphology permits, exchange local detail between size-matched development specimens while retaining their original bodies as evaluation targets. Compare the swapped condition with an identical processing pass using the correct specimen. Ranking by global Chamfer alone may conceal which model preserves identity.
5. **Transfer to reserved real potatoes.** Use fixed supplied registrations and frozen rules for unresolved identity/scale or incomplete reference coverage. Label visible, hidden and indeterminate regions by projecting the independent reference using the camera pose, with a prespecified depth tolerance and a boundary buffer. Quantify real feature accuracy only where the reference and its registration resolve that feature. Evaluate physical volume against verified displacement records and report agreement with SfM volume separately. Cluster repeated frames by tuber. The five local registered pairs support adapter checks; further real performance evidence requires fresh objects. ## A potato-specific follow-up with the released CoRe++ model

Hold XYZ, depth, silhouette, crop and object identity fixed. Recolor only the annotated pin in RGB to another plausible pin color. Use a sham edit at the pin that reproduces its original color, plus a matched-area recoloring of ordinary peel. Compare paired changes in body dimensions, predicted volume and surface geometry across tubers. The depth-only pipeline supplies a negative control and should produce identical predictions. Any change isolates sensitivity to the RGB intervention, while greater change for pin edits than peel edits would support marker-specific sensitivity. Physical marker-free captures would still be needed to measure deployment impact. The CoRe++ discussion already raises the concern; the contribution would be measuring the effect and identifying which predictions it changes.

The CPU body/detail study can proceed with fresh synthetic families. The pin study requires the frozen RGB-D checkpoint, verified pin regions and fresh compatible tuber IDs. Published geometry, robustness and uncertainty methods provide comparisons; none of the proposed outcomes has been established on held-out potatoes in this project.
