## Acquisition brief for a matching test

1. **Enroll a new run.** Use previously unused physical potatoes and give each one a unique `tuber_id` within an explicit `run_id`. Record acquisition date, site, batch or cultivar and hardware configuration. Fix enrollment before reviewing weights or model errors. Keep every enrolled potato in the coverage denominator, including missing data and failed depth checks.
2. **Record one usable center observation per potato.** Save full-resolution RGB, synchronized raw axial depth aligned to that RGB grid, and a binary or alpha mask for the same potato on that grid. Record frame IDs, timestamps, image dimensions, travel axis, exact file paths and `calibration_id`. Keep the sequence around center so the chosen frame can be checked. At 1280 × 720 with matched vertical travel, use the release’s mask bounding-box center nearest row 360 and resolve ties toward the lower position suffix. Freeze any equivalent frame rule for a different resolution or orientation before seeing weights. Use the same selected frame and mask in both arms. [Frozen center rule](protocol.md)
3. **Record scale at the camera.** Save `fx, fy, cx, cy` for the aligned stream in pixels, its resolution, alignment procedure, depth units and invalid codes. Use a nominal 350 mm setup for a direct test. Independently measure the optical-axis distance in mm to the surface supporting potatoes near the center capture position. Record the method and repeatability, tied to the run and camera pose. For a transfer run, freeze the measured standoff and its use in both the common projected area and the L3 height before opening weights. The original 150–400 mm filter may give low coverage at 460 mm. Report that coverage under the frozen gate and specify any separately tested transfer gate in advance. [Frozen depth rule](protocol.md) · [Support measurement audit](../regional_shape_v1/calibration_data_audit.md)
4. **Weigh independently and keep the targets separate.** After imaging, use a tared digital scale to record grams with the same registration tack still attached. Record scale resolution, session check and tack status. Deliver `run_id,tuber_id,weight_g_inctack` in a separate table with one row per potato. Keep a record of missing measurements. If the protocol uses no tack, document the target change in advance. Water-displacement volume is optional. [Original target definition](protocol.md)
5. **Freeze before the weight join.** Record the roster, selected frames, calibration, failure rules and unmodified [L0/L3 coefficients](train_fit.json). Use the shared silhouette area and aspect ratio and add only the frozen camera-height predictor in L3. The original rule accepts `150 ≤ z < 400` mm, requires at least 100 accepted pixels covering at least half the mask, and uses belt depth minus the fifth percentile of accepted depth. Save both predictions before joining scale weights by exact run and tuber ID. Report coverage of both arms, both MAEs on the common scorable IDs, and paired L3-minus-L0 absolute error with a 95% whole-potato bootstrap interval (10,000 draws, seed 5272401). Scope a single-run estimate and its interval to that acquisition. [Frozen scoring protocol](protocol.md)
