# Held-out confirmation of the SAM 2 peel-click protocol

Enroll all eligible exact IDs among the PointRAFT public test split after the existing three-frame weight-study exclusions. Audit the 46 remaining candidates against prior recruited objects and reservations. Keep any overlapping object, including reserved objects, outside this experiment. Use ZIP central directories, the release's pin annotation index and measurement table schema plus exact-label row existence for eligibility. Require the annotated entry-to-center RGB sequence and the selected center raw depth. Exclude ambiguous or absent required files or missing pin labels at any frozen frame. Archive every reason. Freeze the selected cohort, frames, randomized order, code and analysis before reading any held-out response, model prediction, measured weight, or thickness value. Access the frozen entry RGB(A) payloads afterward to prepare the operator stimuli. No other study cohorts are reopened.

For each tuber use the released PLY suffix nearest 360 px, breaking ties toward the smaller suffix, as in the weight development study. The suffix denotes the reversed image-row coordinate of the potato box midpoint. Use the earliest released RGB suffix as entry and all released RGB frames through the selected center, sorted numerically. Require a sequence with distinct entry and center, one consistent RGB archive, an exact RGB filename and pin polygon record for each frame, and a matching center depth file. No substitute frames. Do not load PLY geometry. A candidate needs exactly one matching measurement row with the required field names present in the schema. Check measurement values only after the click freeze and retain late failures in the enrolled denominator. Order IDs by SHA-256 of `sam2-human-confirmation-v1/133/` followed by the exact ID.

Use one first-time operator who has seen none of the selected scenes, the development results, or the failure overlays. Give them only the page and its instruction. Reuse the coached repeat’s exact instruction, same collector, uncomposited full-scene RGB, and same external coarse arrow generated from the annotation bounding box with the frozen background-brightness rule. Accept the first click or “Cannot identify target” and advance. Freeze the complete CSV and hash receipt before any model run. No retrying trials or replacing responses. A skip stays in the cohort denominator.

Replay each submitted click using the archived CPU FP32 SAM 2.1 Hiera Tiny checkpoint, settings, preprocessing, and propagation to center. Use one prompt at entry. Compare each observed mask with that frame’s provided potato alpha and rasterized released pin polygon. The primary endpoint is center potato IoU ≥ 0.5 out of every enrolled potato. Report the count, rate, and two-sided 95% exact Clopper–Pearson binomial interval across potatoes. Missing masks, skips and failed tracks count as failures. Separately report entry mask state and whether the track ever reached potato IoU ≥ 0.5 before falling below it at center, as in development. Label a nonempty mask pin-dominant when potato IoU is below 0.5 and over half its predicted pixels cover the released pin. Include the click coordinates and region, immediate and center states, and all failures. Click placement is a descriptive audit with three regions, on or inside the vector pin outline, inside the potato outside that outline, and outside the intended potato. The interval reflects potatoes in one operator session.

Use the same release histogram filter with measured `x3_depth_mm`, raw depth, released intrinsics and frozen Model A. Reconstruct geometry for both the human center mask and the provided alpha from the same center depth. Compare each prediction with the same exact-ID `weight_g_inctack` measurement in grams. Use the paired subset where both numeric errors are available, including numeric estimates produced by poor masks. Report paired scorable coverage out of all enrolled potatoes, both MAEs on those identical IDs, and the mean paired human-minus-provided absolute error with a two-sided 95% percentile interval from 10,000 tuber bootstrap draws with seed 5272401. Record every unavailable weight and its reason. Score one frozen collection once, resuming incomplete compute with the same frozen receipt and saved tracks. Do not tune using the confirmation results.
