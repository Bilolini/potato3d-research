# One-frame CoRe++ pin-color sensitivity pilot

Use development tuber 2R1-10, frame 364, to test whether a change to pin RGB propagates from the encoder into predicted geometry. Its unchanged CPU audit verified preprocessing and checkpoint loading. The two released-mode passes had identical latents, but active decoder dropout changed their meshes. Two passes establish that this variation exists. They do not estimate a noise threshold for edits. [CPU audit](corepp_cpu_audit.md)

1. **Establish a paired replay.** Retain the audited module modes, fixed grid, pixel preprocessing and one CPU thread. Snapshot the initial model state including buffers. For each condition restore it, and reset the same random state immediately before each corresponding stochastic operation. Use seeds 133 through 148 inclusive, pairing conditions separately at each seed. Use fixed mesh-distance sampling. First compare the original input against a no-op RGB edit passed through the full edit pipeline. Expect identical input tensors, latents, signed distances and grid labels for each pair, equal volumes, and zero geometric displacement up to numerical precision. Resolve replay discrepancies before running color edits.
2. **Define the two color interventions before inference.** In the RGB crop trace the visible colored pin head inside its annotation box. Archive the binary mask, overlay and edit before accessing edited predictions. Pick one alternate pin hue visible in a development image and document its source. Retain texture and shading. On ordinary peel translate the same mask without rotation to a disjoint valid patch at similar distance from the silhouette. Apply the same per-pixel RGB differences as the pin edit. Select the patch using image information alone, minimize clipping, and report actual changed-pixel counts and RGB-change magnitudes after preprocessing for both edits. Save all inputs. Verify input differences occur only on the intended pixels and that depth, crop, mask and grid are identical across conditions.
3. **Locate the response.** For each edit compare against the original at the same seed. Record latent L2 change, mean absolute signed-distance change on the fixed grid, changed inside/outside counts, signed and absolute volume change, and symmetric surface distance. Record any mesh failure. Primary descriptive comparison is the paired difference between pin and peel in mean symmetric surface displacement. Report median and range across seeds, plus the per-seed values; these are repeated runs on one tuber. Equal grid classifications can leave the hull unchanged even when continuous predictions differ.
4. **Interpretation.** A reproducible pin response exceeding the peel response warrants a multi-tuber development protocol. A similar response to both edits supports general local RGB sensitivity in this frame. If only latent or continuous grid values change, report the stage reached. The developmental reference supplied this fixed grid extent, so the pilot measures within-frame sensitivity and cannot establish deployment accuracy. Return the pilot to the research chat before expanding the cohort.
