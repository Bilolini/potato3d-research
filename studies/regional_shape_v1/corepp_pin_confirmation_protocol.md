# Fresh-potato CoRe++ pin recoloring protocol

The endpoint is predicted shape sensitivity to changing the annotated pin's color, compared with applying the same RGB differences to peel. The developed assay and grid are fixed. [Development protocol](corepp_pin_multituber_protocol.md) · [Grid-boundary check](corepp_pin_grid_boundary/report.md)

## Eligibility and selection

Use the full-data split generator in the pinned CoRe++ release. Apply its train, validation and test rules to the 339 labels in the dataset metadata and require the published 237 / 51 / 51 counts. The example split files refer to the five-object demo. The dataset trait CSV's `exp_split` is a separate dataset field. Report both labels and identify the full checkpoint split as reconstructed from released code, because the weight files supply no separate object ledger. [CoRe++ split code](https://github.com/UTokyo-FieldPhenomics-Lab/corepp/blob/0d6bae40b9215332efd566e6bca83bea171b99e9/data_preparation/make_splits.py) · [Model paper, §2.1.4](https://www.ipb.uni-bonn.de/wp-content/papercite-data/pdf/blok2025cea.pdf#page=4) · [Dataset release](https://huggingface.co/datasets/UTokyo-FieldPhenomics-Lab/3DPotatoTwin)

Exclude the five demo IDs, twelve development IDs and both previously scored 36-object rosters. Exclude dataset registration warnings, interpreting the apparent `2R306` spelling as `2R3-6`. For each remaining ID, require one registered pair specifying its own RGB-D frame, both PNG members in the release ZIP directories, and one released valid polygon annotation on that RGB frame. Use the trait CSV for cultivar and acquisition ROS bag. Work from names, ZIP directories and metadata only through roster freeze. An eligible potato is fresh to our analyses regardless of training exposure. The roster includes released model-test objects only.

Select up to 36 potatoes by round-robin over acquisition groups. Order groups and IDs within each group by SHA-256 of `corepp-pin-confirmation-v1/` concatenated with the group or ID. Take every qualifying test object when fewer than 36 qualify. Keep all selected potatoes, including input, replay or scoring failures, in the roster denominator. Neither closed cohort is reopened.

## Frozen inputs and one score

Use the exact development preprocessing, masked pin contours, donor colors, greedy translated peel selection, common integer RGB cap, and same 30³ lattice bytes. Freeze visual flags before any scoring. Keep valid flagged patches as selected, record the flag, and retain failures without substitutions. Run the full paired no-op replay on the expanded mesh path before edited inference, under seeds 133–148 with the archived interior batching at those seeds and the fixed added-point batch at 10133–10148. Test exact tensor, latent, interior and added signed distances, labels, mesh arrays and volume, allowing only the previous numerical tolerance for mesh self-distances. A potato requires all 16 exact replays with valid meshes. Cache verified unchanged latents, signed distances and mesh arrays for the score, with their hashes. Edited predictions use the same per-condition model resets and paired streams, once per condition and seed.

Use the development surface distance implementation. Within each seed subtract the mean displacement of the three peel edits from the pin displacement, then take the median over the 16 paired seeds. Require a complete set for a potato-level result. Report the complete-case mean with equal potato weights, median, and positive / zero / negative counts alongside selected and evaluable denominators. The secondary contrast uses the peel patch with the largest median displacement across seeds per potato, breaking ties by patch order. Subtract that fixed patch within each seed and take the median across seeds. Report means after omitting each selected acquisition group for both contrasts and record any no-effect or coverage failures.

Use a 20,000-draw acquisition-group percentile bootstrap with NumPy PCG64 seed 5273201 for the 95% intervals. Resample the observed number of evaluable acquisition groups with replacement. In each draw keep every evaluable potato in its drawn group and divide the summed contrasts by the drawn potato count, preserving the equal-potato estimand. Use the same group draws for both endpoints. Treat the intervals as descriptive when fewer than six acquisition groups contribute evaluable potatoes. This conservative rule reflects the fragility of resampling few independent units. No inferential confirmation is declared in that case. Otherwise declare the primary mean confirmed only when the entire group interval is above zero. State whether the strongest-peel estimate remains positive and whether its interval excludes zero under the same group-coverage rule. The scope is prediction sensitivity on the released model-test split. The study does not use reference geometry or score reconstruction accuracy.
