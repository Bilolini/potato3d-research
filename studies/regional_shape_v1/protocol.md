# Does visible regional shape improve prediction of the potato underside?

## Decision

Test whether a broad rise or depression in a top scan improves the predicted underside height directly beneath it, after accounting for a smooth body fitted to the scan. The unit of evidence is one tuber. This is a CPU development study using the same 12 tubers and existing archives. The measured result of the preceding lobe study was zero tubers with both a corroborated local feature and an eligible control. A regional measurement uses continuous signed heights on a common footprint and can include a smooth potato. [Previous pilot](../real_lobes_v1/fresh_pilot_report.md)

## First experiment

1. Reuse the fresh-pair intake, fixed registration, RGB-D marker/boundary/depth masks and reference ray checks. Use only the visible scan for the footprint, the smooth-body prediction, and the regional correction. Record body-fit failures. Compute all three predictions on the same cells.
2. Use the body's fitted footprint ellipse to assign 1 mm grid cells to two normalized radial bands (0.25–0.50 and 0.50–0.75) and eight equal angular sectors per band. Use the fitted ellipse axes. Resolve orientation consistently within each tuber. For each sector, take the median signed difference between observed top and fitted top on supported, screened cells. Subtract the mean of the eight sector medians within that band. This removes a global height or radial offset from the candidate correction.
3. Compare three underside predictions. The baseline is the smooth body's lower surface. For aligned reflection, subtract the corresponding centered sector residual from the baseline lower height. For the location control, cyclically shift the eight corrections within the same band by each of the seven nonzero offsets. Average the seven resulting **errors**. All variants share the same fitted body, correction scale, units and support. Use unmodified signed regional estimates for this measurement. Record any predicted belt penetration separately.
4. As initial development settings, require at least 20 valid cells and 50% coverage of nominal sector cells for both scan and reference in every sector of a band. Report the number of evaluable bands and tubers and every exclusion. Estimate error as mean absolute vertical distance in mm on common cells, then average sectors, evaluable bands, and finally tubers with equal weight at each level. Save paired per-tuber differences for aligned minus baseline and aligned minus shifted. A negative difference favors aligned reflection.
5. Check measurement reliability. Measure regional top relief independently on the registered SfM top and compare it to scan relief. Repeat scoring with the four existing lateral registration probes and with ±1° reference rotations about each belt-plane axis through the scan centroid. Report contrasts on support common to the nominal and perturbed runs. Record loss of coverage. On analytic fixtures, verify signs, an aligned bilateral broad deviation, a top-only deviation, and a displaced lower deviation.

## Decision after development

Return denominators, a per-tuber table, paired differences, alignment sensitivity, and an example showing the predicted and measured regions. Report how the fitted body and the existing clipped 95th-percentile mirror perform on the same cells as an additional practical comparison. A result beating the shifted control but failing to improve on the body would show that location carries information while full-strength reflection is a poor predictor. A favorable mean concentrated in one tuber or reversed by small registration perturbations calls for measurement review.

These settings were selected for development and have no established agronomic calibration. Before confirmation, use the development yield and error variability to specify usable coverage, a meaningful improvement margin, and a separate object-level cohort. Prior scored holdouts stay closed. At the end of the development run, return to the research chat for the decision.
