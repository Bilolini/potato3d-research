# Does color sensitivity follow the pin pixels when they move?

The finished study found greater surface displacement from pin recoloring than from matched peel recoloring on 25 of 29 fresh tubers. The locations differed in both their starting RGB appearance and their surrounding image and depth. This one-frame development experiment exchanges the starting RGB patches while keeping the two sites and their depth fixed. [Results](corepp_pin_findings.md)

## One frame, two layouts

Use only pilot tuber 2R1-10, frame 364, with its archived pin contour, translated peel mask, integer pixel correspondence and realized RGB delta map. The archived edits accepted exactly the same deltas without clipping at both sites. Use the archived expanded grid and verified paired decoder procedure. [Pilot inputs](corepp_pin_pilot/frozen_inputs.json) · [Grid procedure](corepp_pin_grid_boundary/report.md)

1. Construct two base RGB inputs. The native input is the original. In the swapped input exchange the RGB triplets between corresponding pin and peel pixels. Leave all other pixels, depth, alpha, crop and camera information fixed. Apply the same code path with an identity copy for the native layout and verify that swapping twice restores the original byte for byte.
2. In each layout produce two single-site edits by applying the archived delta map to the original pin location or to the original peel location. Verify identical realized RGB changes at model input, with zero clipping, and hash the six inputs before edited inference. Save enlarged crops of both layouts and both sites. Record visible seams and RGB/depth inconsistencies before inference. This is a synthetic patch exchange.
3. Use seeds 133–148 with matched interior and outer-grid dropout draws and identical model-state resets for every condition. Verify no-op replay on both layouts. For each edit measure symmetric surface displacement relative to its own unedited layout at the same seed. Separately report the displacement from the unedited native to the unedited swapped layout. Record latent changes, boundary contacts and mesh failures.
4. At each seed calculate the original-pin-site displacement minus the original-peel-site displacement in each layout. Report each contrast's median and range plus their paired change and sign counts. Verify that the native layout reproduces the direction of the archived pilot at the expanded-grid setting. Keep the original 20-cubed result labeled separately.

If the native contrast is positive and reverses after swapping, sensitivity follows the transplanted RGB appearance on this frame. If it stays positive, the original location retains greater sensitivity under this swap; report how much that advantage changes. A near-zero or seed-dependent contrast leaves the distinction unresolved. Location includes surrounding pixels and fixed depth. A result on this composite cannot establish semantic recognition of pins or the effect of physically removing one. End the run after this frame and return to research review.
