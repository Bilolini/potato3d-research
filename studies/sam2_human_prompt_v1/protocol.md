# One-click human-operator SAM 2 development pilot

Use the exact 40 development IDs and original entry-to-center frame sequences from the archived SAM 2 pin-prompt study. Keep test and reserved cohorts closed. Use one real teammate for the pilot. The collector displays one full, uncomposited original RGB entry image at a time. Remove alpha without modifying RGB. It hides IDs, masks, suggested click coordinates, weights and tracker output. It displays only the randomized position, a coarse target cue, and the response controls. The instruction is “Click once on a clear patch of skin on the indicated potato, away from the registration pin and the potato edge.”

Freeze the order before collection by sorting the SHA-256 digest of the fixed string `sam2-human-operator-order-v1/133` followed by a slash and the exact tuber ID. Each scene in this roster contains multiple visible potatoes or partial neighboring potatoes. To indicate the target, draw a short arrow in a distinct graphics layer. Derive only a bounding box from the provided entry alpha, round the orthogonal box midpoint to the nearest 24 px, and consider the four axial directions. Keep the entire arrow plus its outline outside the target bounding box, with its tip 15 px away. Select the darkest candidate patch by the 90th-percentile RGB brightness, breaking ties by the fixed order below, left, right, above. The darkness rule places the cue on unobtrusive background where available. The arrow indicates a coarse location and remains off the potato and its pin. Save its native coordinates in the private manifest. The tracker uses the untouched RGB sequence without the cue.

Display at native resolution on a sufficiently wide screen and size proportionally to fit narrower windows. Map the displayed image rectangle to zero-based original pixel coordinates by flooring the scaled pointer offsets, with no crop or letterbox. Accept the first primary click, or the explicit “Cannot identify target” response. Either advances. Persist each response before advance, keep out-of-bounds and stale responses from overwriting the file, and resume at the first unanswered trial. No correction or tracking feedback is shown. An explicit skip has no fabricated coordinates and stays in the cohort denominator.

At 40 responses, make a frozen CSV and a hash receipt tied to the trial manifest and this protocol, before running or showing results. Partial collections never start inference. Replay each submitted click using the archived CPU SAM 2.1 Hiera Tiny checkpoint, preprocessing, settings and frame sequence, with no additional prompts. The primary endpoint counts all 40 with center potato-mask IoU ≥ 0.5, including explicit skips and technical failures in the denominator. Use the previous definitions at every frame. A potato mask has potato IoU ≥ 0.5. A pin-dominant mask has potato IoU below 0.5 and more than half its predicted pixels on the pin. Keep other and empty masks separate. For center failures, record whether the immediate click selects the pin, a potato track is acquired and later lost, another failure occurs, or input is absent. Save the immediate prompt state and every propagated frame state so overlapping cases can be identified.

Use the archived raw-depth filter with the same measured thickness and the frozen Model A for weight. Count all scorable numeric weights, including pin predictions, and report MAE against the reference alongside provided-mask MAE on the exact same scorable IDs. Keep all failures visible. Compare the 40 paired center-mask success flags against the archived peel-prompt rule's 34/40, reporting gains, losses and their object IDs. This is a development pilot with a single operator and annotated location cues.
